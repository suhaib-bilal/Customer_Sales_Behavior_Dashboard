# Customer Sales Behavior Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze customer
sales data and understand business performance.

## Objectives
- Analyze total sales and revenue.
- Compare regional sales performance.
- Identify top-performing product categories.
- Track key performance indicators (KPIs).
- Support data-driven business decisions.

## Tools and Technologies
- Microsoft Power BI
- SQL
- Power Query
- Data Cleaning
- Data Visualization

## Project Files
- customer_sales_dashboard.pbix: Power BI dashboard.
- sales_analysis_queries.sql: SQL queries for sales analysis.

## Key Features
- Interactive charts and visualizations.
- Sales performance analysis.
- Regional comparisons.
- Product category analysis.
